| Mechanism | Controlled comparison | Required observations |
| --- | --- | --- |
| Situation formation | Same percepts with and without explicit reference grouping | Task duplication, provenance coverage, late-evidence handling |

| Reflexes | Same verified faults with existing guards versus journaled reflex paths | Denial correctness, false quarantine, owned-process recovery |
| Action feedback | Same action receipts with and without outcome reinsertion | Unknown/success distinction, discrepancy detection, feedback convergence |
| Consolidation | Same historical snapshots with and without scheduled derived projections | Source support, variation preservation, retrieval coverage, latency |

Freeze expected decisions and a held-out corpus before tuning any family. Keep
model, source scope, memory budget, scheduler, and unrelated mechanisms fixed for
that comparison. Expand boundary winners before selecting defaults. Preserve
negative findings. `PERCEPTION-SALIENCE-001` retains the original buffer/advisory
comparison; `SITUATION-PIPELINE-001` registers the new budgets and scenario families.

Hard invariants reject a change regardless of aggregate score: exact canonical
preservation; derived-state provenance; mandatory user responses; quarantined
external/model evidence; no source-policy broadening; one semantic role per model
process; bounded context; fail-closed resources; durable idempotent effects; and
finite action feedback.
