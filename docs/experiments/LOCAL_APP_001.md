# LOCAL-APP-001: local application controls

All new app-side capacity/latency/generation limits are provisional. The settings
surface preserves the current native admission and evidence defaults, and does not
establish that every selectable model fits or performs adequately on the target
Dell. UI upper bounds are engineering limits, not advertised model capabilities.

Deterministic gates cover exact destination consent at send time, stateless
structured OpenAI inputs, evidence byte bounds, sampling isolation, invalid config,
Host/Origin/session boundaries, version conflicts, protected canonical records,
link/path escapes, and upload offsets/collisions. Browser acceptance uses actual
HTTP, DOM and private temporary files; model metadata is a fixture. It checks
navigation, dynamic overrides, editing, upload/download, reload persistence, Trash
restoration and layout widths. These tests contain no paid cloud calls.

Native calibration should vary folder count/fan-out, text/chunk size, disk free
space, model weight/context size, reasoning budget, service latency and worker
cancellation timing. Measure request/scan/copy latency, peak RAM, CPU pressure,
chunk throughput, result coverage and recovery clarity. Search/copy truncation and
partially completed side effects must stay explicit. A failed invariant eliminates
a candidate regardless of speed. Expand an optimum at a sampled boundary before
choosing a calibrated value. Do not tune retrieval/model behavior to a browser
fixture; independent unseen task cases remain required for cognitive acceptance.
